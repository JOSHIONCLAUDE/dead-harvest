# Dead Harvest
A 3D first-person zombie survival game. Hold out wave after wave on a haunted farm, earn points, buy the shotgun and rifle.

Play / install: https://joshionclaude.github.io/dead-harvest/
- Android: `DeadHarvest-Android.apk` from Releases. Windows: unzip `DeadHarvest-Windows.zip`, run `Dead Harvest.exe`.
- iPhone / iPad / Mac / any browser: open the link, then Share > Add to Home Screen.

WASD move · Shift sprint · Click shoot · R reload · 1-3 weapons · E buy. Touch: joystick + buttons.
